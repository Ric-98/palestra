# Palestra

Web app personale per allenamento e alimentazione. Nessun server, nessun account:
i dati restano sul dispositivo, con backup su file.

- `index.html`, `css/`, `js/` — l'app (HTML, CSS e JavaScript puro, senza build)
- `data/` — schede e diete in JSON
- `sw.js` — cache offline e aggiornamento automatico
- `publish.sh` — pubblica una nuova versione
